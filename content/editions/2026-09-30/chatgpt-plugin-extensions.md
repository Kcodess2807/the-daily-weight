TechCrunch reports that ChatGPT plugins now get a sidebar home, interactive panels and file viewers, a Plugin Creator tool, and support for the proposed MCP Events spec for automations.

The developer side is the open-source `mcp-extensions` SDK, Apache-2.0 licensed, in TypeScript and Python. It covers sidebar entrypoints, file handlers and composer mentions.
